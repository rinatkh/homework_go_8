## 03.1 TwoStackQueue

```go
type TwoStackQueue; Push(int); Pop() (int,bool); Peek() (int,bool); Empty() bool; Len() int
```

**Контракт:** FIFO только через два стека. Peek сохраняет front, Empty работает у zero value.

**Пример:** `Push(7),Push(9),Pop(): 7; Push(2),Pop():9`.

**Ограничения:** До 10000 операций; нельзя заменить решение срезом со сдвигом. Bool — явная адаптация пустого состояния.

**Подсказка:** Когда действительно нужен перенос из incoming в outgoing?

**Ожидаемая сложность:** Amortized O(1), отдельный перенос O(n); O(n) суммарно.

**Тесты:** 15 входов с перемежением push/pop, проверка Len/Empty/Peek.

[Оригинал LeetCode](https://leetcode.com/problems/implement-queue-using-stacks/). Условия выше — учебная адаптация с явно указанными изменениями API.

## 03.2 RoundRobin

```go
func RoundRobin(names []string, steps int) []string
```

**Контракт:** Взять имя из начала очереди, добавить его в конец, повторить steps раз. Вход не менять.

**Пример:** `[a,b,c],5 -> [a,b,c,a,b]`.

**Ограничения:** n,steps≤10000; steps≤0 или пустой names -> пустой результат; дубликаты разрешены.

**Подсказка:** Данные очереди и результат живут разное число шагов.

**Ожидаемая сложность:** O(n+steps) времени, O(n+steps) с результатом.

**Тесты:** 12 сценариев: пустой, wrap, повторы, Unicode, длинная серия.
