## 02.1 ValidParentheses

```go
func ValidParentheses(text string) bool
```

**Контракт:** Проверить вложенность ()[]{}. Пустая строка корректна, любой другой символ — false.

**Пример:** `{[()]}: true; {(}): false`.

**Ограничения:** Длина≤10000 байт; это расширение исходного LeetCode условием для постороннего символа.

**Подсказка:** Какой тип открывающей скобки должна снять каждая закрывающая?

**Ожидаемая сложность:** O(n) времени и O(n) памяти.

**Тесты:** 14 именованных строк, вложенность, лишние/незавершённые, Unicode.

[Оригинал LeetCode](https://leetcode.com/problems/valid-parentheses/). Условия выше — учебная адаптация с явно указанными изменениями API.

## 02.2 MinStack

```go
type MinStack; Push(int); Pop() (int,bool); Top() (int,bool); GetMin() (int,bool); Len() int
```

**Контракт:** Стек с минимумом текущего содержимого. На пустом читающие методы возвращают 0,false; zero value готов.

**Пример:** `Push(2),Push(1),Push(1),Pop(): минимум ещё 1`.

**Ограничения:** До 10000 операций; min нельзя вычислять полным проходом при каждом запросе. API адаптирован: bool вместо отсутствующего значения.

**Подсказка:** Как запомнить, сколько одинаковых минимумов ещё осталось?

**Ожидаемая сложность:** O(1) амортизированно на операцию при slice-росте, O(n) суммарно.

**Тесты:** 15 наборов, отрицательные, MinInt/MaxInt, повторные минимумы, повторное использование.

[Оригинал LeetCode](https://leetcode.com/problems/min-stack/). Условия выше — учебная адаптация с явно указанными изменениями API.
