# 08. Самостоятельная лаборатория — 1 задача

## 08.1 BenchmarkStructures

`func BenchmarkStructures(b *testing.B)` в internal/benchmark/tasks_test.go. Замените b.Fatal TODO собственными b.Run/b.N. Go 1.22, без b.Loop. Сначала реализуйте нужные структуры, затем измеряйте.

Контракт: сравнить минимум список/slice search и известную позицию, две LIFO/FIFO-реализации, custom hash/map/slice с одинаковыми ключами, byte-накопление и отдельно ring-cyclic. Размеры 100/1000, для чтения дополнительно 10000; seed 7. Каждый подбенчмарк возвращает/сохраняет использованный результат в sink и проверяет его после StopTimer. Выделения показывать -benchmem, не печатать внутри таймера, повторить 3–7 раз.

Пример имени: `BenchmarkStructures/lookup/map/n=1000`. Пример результата намеренно не дан: числа должны быть измерены. Подсказка: отделите build от lookup и выберите, входит ли восстановление изменяемой структуры в одну op. Если входит — назовите pair/series/triple и объясните. Если Ring reject-on-full, не сравнивайте отказы с успешными enqueue другой очереди.

Ожидаемая сложность зависит от реализованного алгоритма: выпишите её **до** запуска, затем обсудите константы и n. Нельзя выдавать сравнение известного slice[index] с linear search или накопления с вытеснением за один контракт.

В `benchmark_report.md` запишите Go/OS/CPU/команду/seed, реальные сырые строки, таблицу медиан/min/max, ns/op/B/op/allocs/op, одно отношение времён и ограничения. B/op не retained heap, benchmark не доказывает Big O. До решения `make bench` обязан падать с TODO, а не молча пропускать проверку. После решения тесты правильности структур остаются отдельными от времени.

`make run-benchmark` проверяет только наличие вашей `BenchmarkStructures` и не измеряет скорость. `make test-benchmark` / `make bench-check` реально вызывают её с `-benchtime=1x`: исходная TODO-заглушка должна упасть. Эта проверка включена в восьмую группу GitHub Actions и в `make ci`, потому что обычный `go test` сам benchmark не запускает. Реальные повторные измерения после реализации — `make bench`; отчёт заполняйте своими данными.
