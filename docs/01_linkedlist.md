# 01. linkedlist — 5 задач

Функциональные тесты находятся рядом с TODO в internal/. Решения здесь не приведены. nil и пустой результат эквивалентны по элементам, если явно не требуется handle.

## 01.1 Reverse

```go
func Reverse(head *Node) *Node
```

**Контракт:** Развернуть конечную ациклическую цепочку, переиспользуя именно её узлы.

**Пример:** `[8,3,5] -> [5,3,8]`.

**Ограничения:** n≤10000, nil допустим; без массива значений и новых узлов.

**Подсказка:** Сохраните необработанный хвост до изменения Next.

**Ожидаемая сложность:** O(n) времени, O(1) дополнительно.

**Тесты:** 15 именованных входов, проверяются адреса узлов, не только значения.

[Оригинал LeetCode](https://leetcode.com/problems/reverse-linked-list/). Условия выше — учебная адаптация с явно указанными изменениями API.

## 01.2 MergeSorted

```go
func MergeSorted(first, second *Node) *Node
```

**Контракт:** Слить две неубывающие независимые цепочки. Равные узлы first предшествуют равным second; узлы переиспользовать.

**Пример:** `[1,4]+[1,2,5] -> [1,1,2,4,5]`.

**Ограничения:** Сумма длин≤10000, цепочки не пересекаются и не содержат циклов.

**Подсказка:** Как выбрать следующую голову и не потерять остаток второй цепочки?

**Ожидаемая сложность:** O(n+m) времени, O(1) дополнительно.

**Тесты:** 15 наборов + пустые стороны; stable oracle по указателям узлов.

[Оригинал LeetCode](https://leetcode.com/problems/merge-two-sorted-lists/). Условия выше — учебная адаптация с явно указанными изменениями API.

## 01.3 HasCycle

```go
func HasCycle(head *Node) bool
```

**Контракт:** Определить повторное достижение того же узла; одинаковые Value сами по себе циклом не являются.

**Пример:** `узлы A->B->C->B: true`.

**Ограничения:** n≤10000; связи не менять, pos не передаётся в функцию.

**Подсказка:** Сравнивайте адреса; проверьте fast и fast.Next до второго шага.

**Ожидаемая сложность:** O(n), O(1).

**Тесты:** 12 длин, все возможные позиции входа в цикл и no-cycle; проверяется неизменность связей.

[Оригинал LeetCode](https://leetcode.com/problems/linked-list-cycle/). Условия выше — учебная адаптация с явно указанными изменениями API.

## 01.4 RemoveValue

```go
func RemoveValue(head *Node, value int) *Node
```

**Контракт:** Удалить все совпадения, очистить Next у каждого отсоединённого узла, вернуть новый head.

**Пример:** `[2,1,2,3,2],2 -> [1,3]`.

**Ограничения:** Ациклическая цепочка≤10000, порядок остальных узлов сохранить.

**Подсказка:** Голова тоже может удаляться несколько раз подряд.

**Ожидаемая сложность:** O(n), O(1).

**Тесты:** 15 наборов, targets из данных и отсутствующий; проверяются identity и удалённые связи.

## 01.5 InsertAfter

```go
func InsertAfter(at *Node, value int) (*Node, bool)
```

**Контракт:** После известного узла создать один новый, его Next направить на прежний хвост. nil -> nil,false.

**Пример:** `A(1)->B(3), вставить 2 после A -> A->new(2)->B`.

**Ограничения:** Это сырая цепочка без владельца, в отличие от List classroom. Не искать по значению.

**Подсказка:** В каком порядке переназначить связи, чтобы не потерять B?

**Ожидаемая сложность:** O(1), один новый узел O(1).

**Тесты:** 15 структур, nil/хвост/середина, новый адрес и сохранение старого Next.
