## 06.1 HashTable

```go
func New(capacity int, hasher func(string)uint64) *HashTable; Set(string,int); Get(string) (int,bool); Delete(string) bool; Len() int
```

**Контракт:** Собственная таблица с цепочками, update без нового ключа, load≤0.75, рост/rehash, пустой ключ и значение 0 допустимы.

**Пример:** `Set(a,1),Set(a,4): Len=1, Get(a)=4,true`.

**Ограничения:** n≤10000, минимум 4 buckets; hasher=nil -> FNV-1a, иначе использовать переданную функцию. В table.go встроенная map запрещена, hash/fnv допустим.

**Подсказка:** При новом m индекс ключа нужно пересчитать; существующий ключ надо найти до решения о росте.

**Ожидаемая сложность:** Ожидаемо amortized O(1) при bounded key и хорошем hash; worst O(n) цепочка, resize O(n+m); O(n+m) память.

**Тесты:** 13 размеров × обычный/постоянный hash, 14 специальных ключей, update/delete/reuse, AST-проверка отсутствия map.

## 06.2 Frequencies

```go
func Frequencies(words []string) map[string]int
```

**Контракт:** Посчитать слова, сохранить вход; nil и пустая map эквивалентны на пустом входе.

**Пример:** `[go,api,go] -> {go:2,api:1}`.

**Ограничения:** n≤10000; строки case-sensitive, пустая строка — обычный ключ. Здесь map разрешена.

**Подсказка:** Нулевое значение int упрощает первый инкремент.

**Ожидаемая сложность:** Ожидаемо O(n) при bounded word, O(u) памяти, u уникальных.

**Тесты:** 15 наборов, повторы, отсутствующие счётчики, unchanged.

## 06.3 ContainsDuplicate

```go
func ContainsDuplicate(values []int) bool
```

**Контракт:** Есть ли хотя бы одна повторяющаяся величина? Вход не менять.

**Пример:** `[-1,3,-1] -> true`.

**Ограничения:** n≤10000; built-in map разрешена, ранний выход допустим.

**Подсказка:** Проверить присутствие до добавления очередного значения.

**Ожидаемая сложность:** Ожидаемо O(n), O(u) памяти; цена первоначального выделения тоже часть функции.

**Тесты:** 15 наборов, независимый pairwise oracle и unchanged.

[Оригинал LeetCode](https://leetcode.com/problems/contains-duplicate/). Условия выше — учебная адаптация с явно указанными изменениями API.
